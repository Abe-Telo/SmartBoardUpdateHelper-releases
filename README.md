# Smart Board Update Helper

Download the latest release. It has two files:

- `SmartBoardUpdateHelper-1.0.1.apk` is the installer app.
- `updater-settings.xml` is a blank settings file. Open it and read the instructions inside. Fill in the school name and classroom prefix, then copy it onto the phone with the app. Keep the file name `updater-settings.xml`.

The app does not unlock a board. After the installer submits a classroom, the office still has to approve it before an update can install.
